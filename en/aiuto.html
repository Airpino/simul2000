Simul2000, general help

What the program is, how it is organised, and how to use the controls shared by all the modules.

What it is

Simul2000 is an interactive teaching program on simulation techniques in statistics. It does not replace statistical software for research: it favours graphics, to show dynamically how simulated distributions take shape, how estimates behave in simulated samples, and how they compare with the true values of the parameters.

It is meant above all for lectures and for self-study in introductory courses in statistics and probability: sampling distributions, the law of large numbers, the central limit theorem, confidence intervals, inference in regression and in generalised linear models, time series.

How it is organised

From the main page you choose one of the ten modules; the first nine were already in the old Simul2000, in the same order:

  • Random number generationten univariate distributions and their histogram
  • Sampling distributions of meansthe central limit theorem at work
  • Monte Carlo integrationhit or miss and the sample-mean method
  • Generation methodsinverting the distribution function
  • Regression relationshipsfitted lines and the distribution of the estimates
  • Generalised linear modelslogistic, Poisson and gamma
  • ARMA modelstime series and autocorrelations
  • Bivariate distributionspoint clouds, ellipses, regression lines
  • Interactive regressionpoints moved with the mouse or a finger
  • Mean and maximum likelihoodthe new module, planned in 2003

Most modules have two stages: first a settings screen, where the distribution or model and the size of the simulation are chosen; then the simulation screen, where the results take shape before your eyes. The exceptions are the generation methods and interactive regression, which have a single screen.

The settings screen

  • Distribution or model: chosen from the list; if it has parameters, they appear right below, with sensible suggested values.
  • Size of the simulation: how many numbers, samples or pairs to generate, and how often to update the charts. Frequent updates show the dynamics better; infrequent updates reach the end sooner.
  • Chart ranges: the Suggested values button computes a range suited to the chosen distribution and to the size of the simulation.
  • Initial seed: the same seed repeats exactly the same simulation; New seed suggests a random one.
  • Colours: besides the original colours, a scheme suited to people who find it hard to tell red from green. The choice is remembered.

To start, press OK, to the simulation, which is both at the top and at the bottom of the screen, or simply the Enter key. If a value is not acceptable, a red message explains what to correct.

During the simulation

  • Start / Pause: starts and stops the animated simulation; the Enter key does the same.
  • Complete: runs everything that remains at once, without animation.
  • Generate (in the regression modules): draws a single sample at a time, useful for commenting step by step.
  • Restart: starts again from the initial seed, with the same settings.
  • Settings: goes back to the settings screen.
  • Speed: the slider sets how many updates are shown per second; next to it is an estimate of the total time.

Next to the charts, the tables always compare the simulated values with the theoretical ones: this is the teaching core of every module.

The top bar

  • ← Main menu: goes back to the main page.
  • Italiano: opens the same page in Italian; in the Italian version, English brings you back here.
  • ? Help: opens the page of this help devoted to the module.
  • Save image: creates a PNG file with all the visible charts, laid out as on screen, with the title and parameters of the simulation above and the tables of results and the date below. The file name contains the module, date and time. It is the simplest way to put a result into lecture notes or a presentation.
  • Background: automatic follows the setting of the computer or phone; light and dark force it. In class, with a projector, the light background is usually easier to read.

Resizable windows

In the four-window modules (regression, generalised linear models, ARMA) the windows can be resized, like the independent windows of the original version:

  • the vertical bar between the columns and the horizontal bar between the rows can be dragged with the mouse or a finger; the bar below the windows changes the overall height;
  • the ⤢ button at the top right of a window, or a double click on its title, enlarges it to the whole panel; ⤡, another double click or the Esc key restore the four windows;
  • the layout is remembered; Reset windows returns to the initial one.

The pseudo-random number generator

All the simulations start from uniform pseudo-random numbers, produced by a multiplicative congruential generator in the Park and Miller version:

ai+1 = 48271 · ai mod (231 − 1),    ui = ai / (231 − 1)

The initial seed a0 is chosen in the settings screen. From these uniform numbers, those of the other distributions are obtained with classical methods: inversion of the distribution function (exponential, Weibull, Cauchy, discrete distributions), the Box and Muller method for the normal, the Marsaglia and Tsang method for the gamma, from which the beta, the Dirichlet and the exponential power distribution are derived. Each page of this help gives the methods used in the module.

All computation happens in the browser: no data is sent anywhere.

Use in class

  • With a projector, the light background and the colour-blind friendly scheme work best; it stays readable even with washed-out colours.
  • To comment on single steps: low speed, or an update after every sample, or the Generate button in the regression modules.
  • To show the final result without waiting: Complete.
  • To repeat in class exactly a simulation prepared beforehand: note down the seed.
  • Each page of the help contains a section of teaching suggestions.

Requirements

A recent browser (Safari, Chrome, Firefox, Edge) on a computer, tablet or phone is all that is needed. The program also works offline, opening the files from the program folder; in that case the browser uses its system fonts.

The original version

I conceived Simul2000 in the mid-1990s, for a course of the PhD programme in Computational Statistics in Naples. It was written entirely in Visual Basic, refined in 2000 and last modified in 2003. From the main page you can consult, as a memento of that version, the 2003 manual (in Italian) and the texts of the original online help, recovered from the old WinHelp file.

This web version (2026), written entirely in HTML and fully self-contained, rebuilds the modules of the original with the same teaching ideas, adds some extensions (the X² test, Lp-norm regression, the three-dimensional histogram, partial autocorrelations, saving images) and a module planned at the time and never finished, on the comparison between the mean and the maximum likelihood estimator.
