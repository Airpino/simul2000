Background

Integration with the Monte Carlo method

Hit or miss method: random points are thrown into the unit square; the fraction of points falling below the curve estimates the integral of the function between 0 and 1.

or change the settings below first

Function to integrate (on 0-1)

All functions are scaled so that 0 ≤ x ≤ 1 and 0 ≤ f(x) ≤ 1, so the integral is an area inside the unit square.

Size of the simulation

The sample-mean method estimates the integral as the mean of f(x) over the same random abscissas, without using the ordinates.

Hit or miss: the estimate is the fraction p̂ of points below the curve, and the confidence interval p̂ ± z·√(p̂(1 − p̂)/n) uses the normal approximation to the binomial. Sample-mean method: the estimate is the mean of f(xᵢ), with an interval based on the sample variance of f(xᵢ). Numbers are generated in the browser with a multiplicative congruential generator.
